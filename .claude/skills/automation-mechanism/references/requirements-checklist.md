# 需求输入清单与缺省假设

Use in Step 1. Extract what the user already gave, ask only for blockers, and fill everything else from the "缺省假设" column. Every default that is used must appear in the scheme's `假设条件` table.

## 1. 阻塞项 (缺失时先问, 一次问完)

| 项目 | 为什么阻塞 |
|---|---|
| 产品外形尺寸、重量、材料 (最好有图或照片) | 决定抓取方式、定位方式、所有负载计算 |
| 目标产能 (UPH 或 日产量 + 班次) | 决定布局形式和节拍 |
| 工序/检测项及规格 (公差、判定标准) | 决定工位数量和测量方案 |
| 来料状态与出料要求 (散料/料盘/料管/编带; OK/NG 分几类) | 决定上下料机构 |

If the user cannot answer yet, proceed with clearly marked assumptions and give the scheme as "基于假设的初步方案".

## 2. 完整清单与缺省假设

### 产品
| 项目 | 缺省假设 |
|---|---|
| 尺寸/重量 | 无缺省, 需确认. 用户给了图纸、照片或 3D 模型时, 从中读出外形尺寸并注明 "来源: 图纸/照片估读"; 照片估读的尺寸列为假设 |
| 材料与表面要求 (防划伤、防脏污、防静电) | 外观面不允许划伤, 接触件用 POM/聚氨酯/硅胶 |
| 方向性/正反特征 | 有方向要求, 需防反检测 |
| 磁性 (磁环/磁铁/含磁组件) | 按 `mechanism-library.md` 磁性产品专项处理 |
| 型号数量与换型频率 | 1 个主型号, 换型 ≤ 15 min |
| 来料一致性 (尺寸波动、毛刺、粘连) | 按图纸公差, 无粘连 |

### 产能与效率
| 项目 | 缺省假设 |
|---|---|
| 目标 UPH | 无缺省, 需确认 |
| 每天运行时间 | 2 班 × 10 h = 20 h |
| 综合效率 OEE (稼动率×性能×良率) | 0.85 |
| 节拍设计余量 | ≥ 10% |
| 料仓/料盘换料间隔 | ≥ 30 min 人工补料一次 |

### 工艺与精度
| 项目 | 缺省假设 |
|---|---|
| 定位精度 / 重复定位精度 | 产品公差的 1/3~1/5 |
| 测量系统能力 | GR&R ≤ 10% (可接受), 10%~30% 有条件接受 |
| 压装/装配力 | 按过盈量计算后 × 1.5 |
| 判定逻辑 | 单项 NG 即 NG; 数据异常/未判定按 NG 处理 |

### 物流与人机
| 项目 | 缺省假设 |
|---|---|
| 上料方式 | 人工批量补料到料仓, 设备自动单件上料 |
| 下料方式 | OK 品流道/料盘收料, NG 品落入带锁 NG 盒 |
| 操作侧 | 正面单侧操作, 人机界面在操作侧 |
| 数据追溯 | 每件测试数据存储, 可导出 CSV; 有条码时绑定条码 |

### 环境与公用工程
| 项目 | 缺省假设 |
|---|---|
| 气源 | 0.5~0.6 MPa, 选型按 0.4 MPa 计算 |
| 电源 | AC 220 V 单相 (≥3 kW 或有大伺服时 AC 380 V 三相) |
| 环境 | 室温 15~35 °C, 无洁净度要求, 普通车间振动 |
| 占地/高度限制 | 无特别限制; 推荐设备 ≤ 1.5 m × 1.2 m × 1.9 m (含三色灯) |

### 安全与合规
| 项目 | 缺省假设 |
|---|---|
| 防护 | 全封闭外罩 + 门禁开关; 操作口加安全光栅 |
| 急停 | 操作侧和维护侧各 1 个 |
| 标准 | GB/T 15706 (ISO 12100) 风险评估, GB/T 5226.1 (IEC 60204-1) 电气安全; 出口时另确认 CE 等要求 |

### 商务
| 项目 | 缺省假设 |
|---|---|
| 预算 | 未知, 方案给出成本区间和降本选项 |
| 交期 | 未知, 方案标明长周期件 (DD 马达、进口传感器、定制分割器) |
| 品牌偏好 | 未指定; 气动 SMC/AirTAC, 模组/导轨 HIWIN/THK/国产同级, 伺服 松下/安川/汇川, 传感器 基恩士/欧姆龙/国产同级, 由用户确认 |

## 3. 提问模板

When asking, keep it to one short list, for example:

> 为了给出可落地的机构方案, 还需确认以下 4 点 (其余按常规假设处理, 会在方案中列明):
> 1. 产品尺寸/重量/材料 (有图纸或照片最好)
> 2. 目标产能: UPH 或日产量, 几班生产
> 3. 检测项与判定标准 (例如表磁峰值上下限、外观缺陷类型)
> 4. 来料形式 (散料/料盘/料管) 和 OK/NG 出料要求
