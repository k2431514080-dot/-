# 机构方案评审检查表

Use in Step 8 and whenever the user asks to review an existing scheme. Go through every section; report only the items that are open or risky, as a `风险与对策` table. Do not paste the whole checklist into the answer.

## 1. 功能与工艺
- [ ] 每个工序都有对应机构, 动作表无遗漏 (上料、定位、作业、检测、下料、NG 处理)
- [ ] 来料异常 (尺寸超差、毛刺、粘连、方向错) 的处理方式明确
- [ ] 换型内容与时间明确 (换哪些零件、是否需要重新标定)
- [ ] 检测工位与冲击工位错开, 或时序上避开
- [ ] 3D 概念布局 (`layout3d.py`) 无静态干涉和取放运动干涉; 未检查的运动 (气缸推块、模组滑台、转盘扫掠) 已人工确认

## 2. 精度链
- [ ] 定位基准与产品图纸基准一致
- [ ] 关键精度由定位元件 (销、V 块、硬限位、芯轴) 保证, 而不是由驱动元件保证
- [ ] 取放误差有导向/浮动吸收
- [ ] 测量工位: 定位重复性 ≤ 测量公差的 1/10; 有 GR&R 计划; 有基准设备相关性方法
- [ ] 转盘/摆臂: 角度误差已换算到工位处的线性误差

## 3. 节拍
- [ ] 有动作表和节拍计算, 余量 ≥ 10%
- [ ] 关键路径和瓶颈机构已标出
- [ ] 凸轮分割器方案: 所有工位作业 ≤ 停留时间
- [ ] 供料能力 ≥ 节拍需求 × 1.2
- [ ] 补料/倒料间隔 ≥ 30 min (或已评估停机损失), 补料口/料盒是否需要进入防护区

## 4. 强度、刚性与选型
- [ ] 气缸/吸盘/丝杠/同步带/电机/转盘/导轨均有计算, 计算中的 [注意]/[NG] 已处理
- [ ] 悬臂结构 (模组悬臂、摆臂) 的挠度和导轨力矩已校核
- [ ] 高速运动部件轻量化 (铝合金/减重孔), 惯量比在范围内
- [ ] 压装/冲击工位有背面刚性支撑

## 5. 安全 (GB/T 15706 / ISO 12100 风险评估思路)
- [ ] 危险区全封闭; 门禁开关 + 安全继电器/安全 PLC
- [ ] 操作口安全光栅, 安全距离已计算 (`mech_calc.py safety`) 并实测停止时间
- [ ] 急停按钮在操作侧和维护侧可触及
- [ ] 断气/断电: 垂直轴不下落 (抱闸/单向阀/锁紧气缸), 夹紧不松开 (或松开不造成危险)
- [ ] 人工工位: 双手按钮或光栅保护压装/夹紧动作
- [ ] 气路: 三联件, 主气压力开关 (低压报警停机), 残压释放阀
- [ ] 电气: 接地、线缆防护、电柜散热, 符合 GB/T 5226.1

## 6. 防错 / 防呆
- [ ] 有料/无料、单件/双料、正反方向检测
- [ ] 每个气缸动作有到位确认 (磁性开关), 超时报警
- [ ] 真空吸附有压力确认, 掉件报警
- [ ] 治具防反 (定位销不对称), 换型件防错装
- [ ] 未判定/数据异常/通信超时按 NG 处理; NG 剔除确认; NG 盒带锁并计数
- [ ] 重启后状态恢复 (转盘上残留产品的处理, 是否需要清料模式)

## 7. 维护与调试
- [ ] 易损件 (吸嘴、夹爪指、探针、同步带、缓冲器) 可快速更换, 列出备件清单
- [ ] 调整机构有刻度/定位基准, 调整后可锁紧
- [ ] 关键零件可从外部拆装, 不需要大拆
- [ ] 润滑点可达, 有润滑周期
- [ ] 有手动/单步/空跑/清料模式

## 8. 制造与成本
- [ ] 优先标准件和成熟模块, 自制件可加工 (避免深腔、超薄壁、难装夹)
- [ ] 公差只在功能需要处收紧
- [ ] 长周期件已标注 (DD 马达、进口传感器、定制分割器、定制凸轮)
- [ ] 成本区分 报价/估算/历史价, 预留调试与设计变更费用 10%~15%

## 9. 数据与接口
- [ ] IO 清单 (气缸×2 磁开、传感器、阀、伺服轴数) 已统计, 控制器点数留 20% 余量
- [ ] 测试数据存储格式、条码绑定、MES 接口明确
- [ ] 测量设备 (高斯计、扭矩传感器、相机) 的通信方式和采样速率满足节拍

## 10. 磁性产品专项 (适用时)
- [ ] 测量区附近无导磁材料和磁源, 已做有/无对比验证
- [ ] 互吸卡料对策 (料管、隔离、分料力核算)
- [ ] 铁屑清洁措施
- [ ] 探头间隙定距方式、产品回转跳动、温度影响、采样同步已说明

## 简化 FMEA 表 (风险与对策)

| 风险点 | 失效模式 | 原因 | 影响 | 严重度 (高/中/低) | 预防 / 检测措施 | 验证方法 |
|---|---|---|---|---|---|---|
| 上料分料 | 双料进入转盘 | 产品互吸/粘连 | 测量误判, 卡机 | 高 | 错位推片 + 单件光纤确认 | 连续 1000 件上料试验 |
| 表磁测量 | 重复性差 | 探头间隙波动 | 误判 OK/NG | 高 | 硬限位定距, 芯轴定位 | 固定位置/随机取放 GR&R |
