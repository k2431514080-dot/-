# 驱动与关键元件选型公式

Each section matches a `scripts/mech_calc.py` subcommand. Run the script instead of hand-calculating; use this file to explain the result, choose inputs, and know what the script does not check. Units: N, mm, MPa, kg, s unless stated. g = 9.807 m/s².

## 1. 气缸 — `cylinder`

- 理论出力: 推力 F = P·πD²/4, 拉力 F = P·π(D²−d²)/4 (P: MPa = N/mm², D/d: mm → N)
- 负载力: 水平 F = μ·m·g + F外; 垂直 F = m·g + F外; 夹紧/压装 F = 所需力
- 所需缸径: D ≥ √(4F / (π·P·η)), 向上取标准缸径 6/8/10/12/16/20/25/32/40/50/63/80/100/125/160/200
- 负载率 η (经验值):

| 工况 | η |
|---|---|
| 静负载 (夹紧、压装) | ≤ 0.7 |
| 动负载 v < 100 mm/s | ≤ 0.65 |
| 动负载 100~500 mm/s | ≤ 0.5 |
| 动负载 > 500 mm/s | ≤ 0.3 |

- 设计压力取 0.4 MPa (供气 0.5~0.6 MPa).
- 耗气量 (ANR, 双作用往返): V = π/4·(D² + D² − d²)·L·(P + 0.101)/0.101 × 10⁻⁶ L; 另加管路 10%~30%.
- 撞击动能 E = ½·m·v², 撞击速度 ≈ 1.4 × 平均速度; E 须 ≤ 样本允许动能, 否则加液压缓冲器或降速.
- 动作时间 ≈ 阀响应 0.03 s + 行程/平均速度 + 到位确认 0.02 s.

Not checked by the script: 活塞杆横向负载 (用导杆/滑台气缸或外导轨)、压杆稳定性 (长行程大推力)、缓冲能力. 垂直/夹紧必须写明断气保持方式.

## 2. 真空吸盘 — `vacuum`

- 理论吸力: F = |P|·A·n, P 单位 kPa 时 F[N] = |P|·0.001·A[mm²]·n
- 要求: F ≥ m·(g + a)·t, 安全系数 t: 水平吸吊 ≥ 4, 垂直 (侧吸) ≥ 8
- 真空度: 非透气件设计取 −60 kPa; 透气件取 −20~−40 kPa 并加大流量
- 真空响应: T₁ = V·60/Q (到达 63%), T₂ = 3·T₁ (到达 95%); V 为吸附侧管路容积 L, Q 为发生器平均吸入流量 L/min (ANR)
- 吸盘选型: 平型 (平面), 波纹型 (高度差/倾斜/缓冲), 材质 NBR (通用)、硅胶 (耐温, 可能留痕)、聚氨酯 (耐磨)、导电型 (防静电)

## 3. 滚珠丝杠模组 — `screw`

| 量 | 公式 |
|---|---|
| 丝杠转速 | N = v / Ph × 60 (v mm/s, Ph 导程 mm) |
| 轴向负载 | F = m·g·(μ·cosθ + sinθ) + F外 |
| 负载扭矩 (电机侧) | T_L = F·Ph / (2π·η·i) + T_拖动 / i (Ph 用 m) |
| 丝杠惯量 | J_s = π·ρ·L·d⁴ / 32 (ρ = 7850 kg/m³) |
| 移动质量换算惯量 | J_W = m·(Ph / 2π)² |
| 加速扭矩 | T_a = (J_M + J_L/η)·α, α = 2π·i·a / Ph |
| RMS 扭矩 | √[(T₁²·t_a + T_L²·t_c + T₃²·t_d + T_hold²·t_dw) / t_total] |
| 危险转速 | N_c = λ·d_r / L_b² × 10⁷ × 0.8; λ: 固定-自由 3.4, 支撑-支撑 9.7, 固定-支撑 15.1, 固定-固定 21.9 |
| DN 值 | d × N ≤ 约 70,000 (常用参考, 以样本为准) |

导程选择: 先由最高速度和电机额定转速定导程 (Ph ≥ v·60/3000), 再看惯量比和分辨率. 丝杠效率 0.9, 预压拖动扭矩约 0.01~0.05 N·m (按样本).

Not checked: 屈曲载荷、额定寿命、静安全系数.

## 4. 同步带模组 — `belt`

| 量 | 公式 |
|---|---|
| 每转移动量 | π·D (D 节圆直径 = z·p / π) |
| 带轮转速 | N = v / (π·D) × 60 |
| 负载扭矩 | T_L = F·(D/2) / (η·i) |
| 换算惯量 | J = (m + m_带)·(D/2)² + J_带轮 |
| 有效张力 | F_e = F + (m + m_带)·a, 须 ≤ 带型许用张力 |

同步带模组惯量比常偏大, 常加 1:3~1:5 行星减速机. 垂直轴同步带有断带坠落风险.

## 5. 伺服电机校核 (screw / belt / rotary 共用)

| 判据 | 默认 |
|---|---|
| 连续扭矩 (RMS) × 安全系数 ≤ 额定扭矩 | 安全系数 1.5 |
| 峰值扭矩 ≤ 0.8 × 瞬时最大扭矩 | 最大扭矩 ≈ 3 × 额定 |
| 最高转速 ≤ 电机最高转速; 超过额定转速时核对 T-N 曲线 | 3000 / 6000 rpm |
| 惯量比 J_L / J_M | 一般 ≤ 10, 高响应 ≤ 5 |

脚本内置 50 W~1 kW 通用中惯量系列典型参数, 只用于定功率等级; 定型时用 `--motor-rated-torque --motor-inertia --motor-max-torque` 按样本复核.

步进电机: 用样本 T-N 曲线 (牵出扭矩) 在工作转速下留 2 倍余量; 惯量比按厂家推荐 (常见 ≤ 10); 高速扭矩衰减明显; 关键轴用闭环步进或伺服防丢步.

## 6. 减速机

- 减速比作用: 让电机工作在额定转速附近; 负载惯量按 1/i² 折算, 降低惯量比.
- 行星减速机回程间隙: 精密型 ≤ 3′, 经济型 8′~15′ (以样本为准). 末端误差 = R × 间隙 (rad).
- 校核: 输出额定扭矩 ≥ 输出侧峰值扭矩; 急停扭矩; 允许径向/轴向负载; 输入转速.

## 7. 转盘惯量与运动曲线 — `rotary` / `indexer`

惯量公式: 实心圆盘 J = ½·m·R²; 圆环 J = ½·m·(R₁² + R₂²); 质点 J = m·r²; 长方体绕中心 J = m·(a² + b²)/12; 平行轴 J = J_c + m·d².

运动曲线无量纲特性值 (脚本数值积分求得):

| 曲线 | Vm | Am | AVm/Am (Qm) | 特点 |
|---|---|---|---|---|
| 修正正弦 MS | 1.76 | 5.53 | 0.99 | 凸轮分割器常用, 综合性能好 |
| 修正梯形 MT | 2.00 | 4.89 | 1.65 | 加速度最小, 速度高 |
| 摆线 Cycloid | 2.00 | 6.28 | 1.30 | 加速度连续 |
| 梯形速度 1/3 | 1.50 | 4.50 | 1.50 | 伺服常用 |
| 三角速度 | 2.00 | 4.00 | 2.00 | 加速度最小但速度最高 |

伺服/DD 转盘: 分度角 θ = 2π/S, 最大角加速度 α = Am·θ/t², 最大角速度 ω = Vm·θ/t; 输出峰值扭矩 = J·α + T_f + T_w.

凸轮分割器:
- 分度时间 t_h = T × θh/360, 停留时间 = T − t_h (所有工位作业必须在停留时间内完成)
- α_max = Am·(2π/S)/t_h², 惯性扭矩 T_i = J·α_max
- 输出所需扭矩 T_e = (T_i + T_f + T_w)·f_c
- 输入所需扭矩 T_c = 360/(S·θh) × [(AVm/Am)·T_i + Vm·(T_f + T_w)] × f_c
- 电机功率 P = T_c·n / 9550 / η (kW), η 蜗轮减速电机约 0.6
- 负载系数 f_c: 平稳 1.0~1.5, 中等冲击/频繁启停 1.5~2.0, 重冲击 2.0~3.0
- 分度角选择: θh 大 → 加速度和扭矩小、运行平稳, 但停留时间短; 先保证停留时间, 再取尽量大的 θh.

## 8. 直线导轨寿命 — `guide`

- 额定寿命: 滚珠 L = (C / (f_w·P))³ × 50 km; 滚柱 L = (C / (f_w·P))^(10/3) × 100 km
- 寿命时间 L_h = L × 10⁶ / (2 × 行程 × 往返次数/min × 60)
- 负荷系数 f_w: 低速无冲击 1.0~1.5, 一般 1.5~2.0, 高速有冲击 2.0~3.5
- 静安全系数 f_s = C₀ / P_max: 一般 ≥ 1~3, 有冲击振动 3~5
- P 为单滑块等效负荷, 需按悬臂力矩和偏载分配到各滑块后计算.

## 9. 点到点运动时间 — `move`

- 加速度 a, 最高速度 v, 距离 L: 若 L ≥ v²/a 为梯形, t = L/v + v/a; 否则为三角, t = 2√(L/a)
- 加整定时间 0.02~0.1 s (伺服) 或到位确认 0.02~0.05 s.

## 10. 安全光栅安全距离 — `safety`

- ISO 13855 (GB/T 19876), 手/手指检测 (分辨率 d ≤ 40 mm), 垂直接近:
  S = K·T + C, K = 2000 mm/s, C = 8·(d − 14); S > 500 mm 时以 K = 1600 重算且 S ≥ 500 mm; S ≥ 100 mm
- T = 光栅响应 + 安全控制器响应 + 机器停止时间 (实测, 含伺服制动和气缸排气)
- 另需防止从上方/下方/侧面绕过光栅和人员站入危险区.
