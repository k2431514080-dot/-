# 机构库: 功能 → 候选机构

Use in Steps 3–4. For each action in the action table, find its function below, compare the candidates, and record why one was chosen. Values are typical scheme-stage figures; confirm with vendor data. Cost levels are relative (低/中/高) because prices vary by brand and year.

## 0. 总体布局

| 布局 | 适用 | 优点 | 缺点 | 节拍量级 |
|---|---|---|---|---|
| 转盘式 (凸轮分割器 / DD / 伺服+减速机) | 小件, 4~12 工位, 各工序时间接近 | 紧凑, 工位间定位一致, 节拍快 | 工位数受直径限制, 最慢工位决定节拍, 后期加工位难 | 0.8~3 s/pcs |
| 直线同步式 (步进梁/同步移载) | 工位多, 产品可同步移载 | 扩展性好, 结构直观 | 同步移载机构复杂, 任一工位故障全线停 | 1~5 s/pcs |
| 直线异步 + 治具回流 (倍速链/皮带线) | 工序时间差异大, 有人工工位 | 工位独立, 可加缓存, 易扩展 | 治具多, 占地大, 成本高 | 3~20 s/pcs |
| 机器人工作站 (SCARA/六轴 + 周边) | 多品种, 动作复杂, 中等产量 | 柔性高, 换型快 | 单机节拍受机器人限制, 成本高 | 2~10 s/pcs |
| 环形线 / 磁悬浮输送 | 高速多工位, 柔性要求高 | 动子独立控制, 可变间距 | 成本高 | <1~3 s/pcs |
| 单工位 + 人工上下料 | 小批量、验证阶段 | 便宜, 快 | 依赖人工, 一致性差 | 5~30 s/pcs |

Rules:
- 全检/测试机, 产品 < 50 mm, 检测项 ≤ 5: 先考虑转盘式.
- 某工序时间 > 其他工序的 2 倍: 该工序做双工位/双头并行, 或改直线异步加缓存.
- 型号多、换型频繁: 机器人工作站或快换治具 + 视觉定位.
- 测量工位远离冲击源 (压装、推料、分度冲击), 或在测量时序上避开冲击动作.

## 1. 供料 / 上料

| 机构 | 适用 | 优点 | 缺点 / 风险 | 成本 |
|---|---|---|---|---|
| 振动盘 + 直振 + 分料 | ≤ 30 mm 小件, 大批量, 外形可机械定向 | 供料快, 自动定向 | 换型需换盘/轨道; 噪音; 划伤; 调试周期长; 磁性件互吸卡料 | 中 |
| 柔性振动盘 + 视觉 + 机器人 | 多品种、难机械定向 | 换型只改程序 | 节拍受视觉和机器人限制 | 高 |
| 料管 / 弹匣叠放 + 底部推料 | 片状、环状、柱状件 (含磁环) | 结构简单, 无互吸卡料 | 需人工装管; 料管容量决定补料间隔 | 低 |
| 料盘 (Tray) + 模组/机器人取放 | 精密、易损、来料已排列 | 不伤件, 位置确定 | 需空盘/满盘交换机构; 取放节拍较慢 | 中~高 |
| 编带 + Feeder | 电子元件 | 标准化, 可靠 | 仅限编带来料 | 中 |
| 阶梯式上料机 | 轴、杆、销类 | 无划伤, 噪音低 | 仅适合长径比大的件 | 中 |
| 人工放料 + 防呆治具 | 低产量、验证阶段 | 最便宜 | 节拍和一致性依赖人工 | 低 |

Rules:
- 供料能力 ≥ 设计节拍需求 × 1.2~1.5.
- 上料口必须有 "有料/缺料" 检测和缺料报警; 料仓剩余量预警.

## 2. 分料 / 隔离 (一次放行一个)

| 机构 | 适用 | 说明 |
|---|---|---|
| 错位分料 (气缸推块/推片) | 直振出口、料管底部 | 推片厚度 ≤ 单件厚度; 磁性件需按互吸力核算推力 |
| 双挡停 (插针/挡块交替) | 皮带线、滑道 | 两个挡停时序互锁, 防止连放 |
| 分料轮 / 星轮 | 圆柱件高速分料 | 分料节拍高, 需与下游同步 |
| 真空吸取分离 | 薄片粘连 | 配合吹气分层 |

分料位必须有单件确认 (光纤/对射), 防止双料进入下工位.

## 3. 搬运 / 取放

| 机构 | 适用 | 典型往返节拍 | 重复精度 | 优点 | 缺点 | 成本 |
|---|---|---|---|---|---|---|
| 双气缸 XZ (滑台/导杆气缸) | 两点取放, 负载 < 2 kg | 1.0~1.6 s | ±0.02~0.05 mm (靠硬限位) | 便宜, 可靠, 好维护 | 只能两点; 中间位置不可控; 冲击大需缓冲 | 低 |
| 凸轮式取放机构 | 两点高速取放 | 0.3~0.8 s | ±0.02 mm | 快且平稳, 轨迹固定 | 不可调, 改行程需换凸轮 | 中 |
| 摆臂 (旋转气缸/伺服 + 升降) | 角度取放, 转盘上下料 | 0.8~1.5 s | 气缸 ±0.05 / 伺服 ±0.02 mm | 占地小 | 摆臂惯量限制速度 | 低~中 |
| 直角坐标 (伺服模组 XY/XYZ) | 多点 (料盘), 行程大 | 1.0~2.5 s | 丝杠 ±0.01~0.02 / 皮带 ±0.04~0.1 mm | 可编程, 行程灵活 | 速度一般, 悬臂刚性需校核 | 中 |
| SCARA | 平面多点, 负载 ≤ 10 kg | 门型标准循环 0.3~0.6 s (取放实际 0.8~1.5 s) | ±0.01~0.02 mm | 快, 柔性 | 成本较高, 有工作半径限制 | 中~高 |
| 六轴机器人 | 空间姿态、翻转、复杂轨迹 | 1.5~4 s | ±0.02~0.05 mm | 最灵活 | 节拍慢于 SCARA, 成本高, 需安全防护 | 高 |
| Delta 并联 | 轻小件 (≤ 1~3 kg) 高速分拣 | 0.3~0.6 s | ±0.05~0.1 mm | 极快 | 负载小, 精度一般 | 高 |
| 直线电机模组 | 超高速/超高精 | 0.2~0.5 s | ±0.001~0.005 mm | 快, 无反向间隙 | 贵, 需散热和防磁屑 | 高 |

Rules:
- 两点、负载小、精度 ≥ ±0.05 mm → 双气缸; 节拍不够 → 凸轮取放或双吸嘴 (一次取放两件).
- 取放精度不足时, 不提高手臂精度, 而是在放料位加导向 (锥面/倒角/浮动吸嘴) 吸收误差.
- 垂直轴断气/断电不得掉落: 气缸用单向阀或锁紧, 伺服用抱闸.

## 4. 末端执行器

| 末端 | 适用 | 注意 |
|---|---|---|
| 真空吸盘 | 有 ≥ 吸盘直径的平面 | 中孔件、透气件漏气; 真空开关确认吸附; `mech_calc.py vacuum` |
| 平行气爪 (两指) | 外形规则 | 夹持力 ≥ 工件重量 × 10~20 (摩擦夹持); 需夹爪让位空间 |
| 三爪 / 内撑气爪 | 环形件、轴承、磁环 | 内撑自定心, 不碰外圆测量面 |
| 电动夹爪 | 易损件、夹持力需可控、多尺寸 | 成本高于气爪 |
| 磁吸 (电磁/永磁) | 钢件 | 磁性产品禁用 (位置不定, 释放困难, 干扰测量) |
| 伯努利 / 非接触 | 薄片、晶圆 | 横向需限位 |
| 浮动吸嘴 / 浮动接头 | 放料位有导向时 | 吸收 0.1~0.5 mm 位置误差, 防压伤 |

## 5. 输送 / 移载

| 机构 | 适用 | 说明 |
|---|---|---|
| 平皮带线 | 轻小件、料盘 | 定位靠阻挡 + 侧靠; 不适合精定位 |
| 倍速链 + 治具 | 异步装配线 | 阻挡 + 顶升定位销定位, 定位精度 ±0.05 mm 级 |
| 同步带线 / 步进梁 | 同步移载 | 每次移动一个工位距 |
| 转盘 | 见第 7 节 | 工位间定位一致 |
| 环形线 / 磁悬浮 | 高速柔性 | 动子独立控制 |

## 6. 定位 / 夹紧

| 方式 | 适用 | 说明 |
|---|---|---|
| 一面两销 (圆柱销 + 菱形销) | 有两孔的板类件/治具 | 标准做法, 防反 |
| V 型块 + 侧推 | 轴类、环类外圆 | 自定心, 侧推力指向 V 块 |
| 芯轴 / 胀芯 | 环形件以内孔为基准 | 保证同轴度 (回转测量必备) |
| 两面靠 + 侧推 | 方形件 | 先靠 X 再靠 Y, 推力指向基准面 |
| 真空吸附平台 | 薄件、软件 | 需平面度 |
| 快速夹钳 / 肘节 | 人工工位、大夹紧力 | 自锁, 断气不松 |
| 弹簧夹紧 + 气缸松开 | 断气需保持夹紧 | 失效安全 |

Rules:
- 定位基准与产品图纸基准一致; 定位和夹紧分开: 先定位, 后夹紧, 夹紧力指向定位面.
- 不要过定位: 内孔定位销/芯轴已定位时, 不要再加侧推 + V 块; 套在销上的产品只能垂直取出 (吸取/夹取), 不能侧推剔除.
- 自动放料的定位口要有导向倒角, 配合间隙按 "取放误差 + 产品公差" 设计.
- 定位重复性 ≤ 测量公差的 1/10 (测量工位).

## 7. 旋转 / 分度 / 翻转

| 机构 | 适用 | 精度 (典型) | 优点 | 缺点 | 成本 |
|---|---|---|---|---|---|
| 旋转气缸 (齿轮齿条/叶片) | 90°/180° 两点 | 靠限位调整 | 便宜 | 允许动能小, 惯量大需降速 | 低 |
| 伺服 + 减速机 + 转盘 | 任意分度, 中等精度 | 受回程间隙影响 (精密行星 ≤3′, 经济型 8′~15′) | 柔性, 成本适中 | 精定位需加定位销 | 中 |
| 凸轮分割器 | 固定分度, 高速 | ±30″~±60″ | 高速平稳, 自锁, 精度高 | 分度数固定; 停留时间受分度角限制 | 中 |
| DD 马达 | 任意分度, 高精度 | 重复 ±几″ (依型号) | 无间隙, 可变分度, 高刚性 | 贵, 需刹车/负载惯量评估 | 高 |
| 翻转机构 (旋转气缸 + 夹爪) | 正反面加工/检测 | — | 简单 | 翻转中掉件风险, 需夹持确认 | 低~中 |

转盘位置误差 = 回转半径 × 角度误差: R = 160 mm 时, 5′ 间隙 ≈ 0.23 mm, 30″ ≈ 0.023 mm. Use `mech_calc.py rotary/indexer` with `--backlash-arcmin/--accuracy-arcsec`.

## 8. 压装 / 装配

| 方式 | 力范围 (量级) | 说明 |
|---|---|---|
| 气缸直压 | ≤ 3 kN (Φ100 @0.4 MPa ≈ 3.1 kN) | 无力-位移监控, 需加压力传感器或位移限位 |
| 气液增压缸 | 1~10 t 级 | 力大, 速度快, 无精确位置控制 |
| 伺服压机 | 0.5~50 kN 级 | 力-位移曲线监控, 窗口判定, 可追溯 |
| 肘节 / 杠杆增力 | 视结构 | 行程末端增力, 适合铆压 |

Rules: 压装力 ≥ 计算压入力 × 1.5; 压头导向 + 浮动接头 + 背面刚性支撑; 用力-位移窗口判定压装是否到位.

## 9. 检测 / 测量

| 手段 | 典型用途 | 说明 |
|---|---|---|
| 2D 视觉 | 定位、有无、尺寸、外观 | 精度由视野/像素决定: 单像素尺寸 = 视野 / 像素数, 量测精度约 1~3 像素 |
| 3D 线激光 / 结构光 | 高度、平面度、段差 | 需相对运动扫描或面阵 |
| 激光位移 / 接触式位移 (数字测头) | 单点高度、跳动 | 接触式 µm 级, 注意测力和测头磨损 |
| 霍尔探头 / 高斯计 | 表磁 (磁环、磁铁) | 见第 11 节 |
| 扭矩传感器 + 伺服 + 编码器 | 旋转阻尼扭矩、段落感 (滚轮手感) | 扭矩-角度曲线, 峰谷值, 采样与角度同步 |
| 力传感器 | 按键力、插拔力、压装力 | 力-位移曲线 |
| 麦克风 + 隔音罩 | 噪音、异音 | 背景噪声需比被测低 ≥ 10 dB |
| 电性能测试 | 通断、电阻、绝缘 | 探针寿命与接触可靠性 |

测量工位规则: 测量与冲击动作错开; 每班用 OK/NG 标准件点检; 自制设备与基准设备做相关性; 做固定位置重复测试和随机取放重复测试, 区分测量重复性和定位重复性.

## 10. 分拣 / 下料

| 方式 | 适用 | 说明 |
|---|---|---|
| NG 推料气缸 / 吹气剔除 | 转盘、流道 | 剔除后传感器确认落入 NG 盒 |
| 翻板分道 | 流道多档分选 | 翻板位置确认 |
| 取放分仓 | 多档分级 (按测量值分 bin) | 每仓计数, 满料报警 |
| 料盘 / 料管收料 | 精密件 | 满盘自动换盘或报警 |

失效安全: 未判定、数据异常、通信超时一律按 NG 处理; OK 通道只在收到 OK 判定后打开; NG 盒带锁并计数, 计数与判定次数核对.

## 11. 磁性产品专项 (磁环 / 磁铁 / 磁阻尼模组)

- 材料: 产品流道和测量区附近零件用铝合金、奥氏体不锈钢 (316 优于 304, 304 冷加工后有弱磁性)、POM/PEEK/电木. 避免碳钢、马氏体/铁素体不锈钢 (420/430)、钢制导轨滑块和电机靠近探头. 距离按实测确定: 做 "有/无该零件" 对比测量.
- 互吸: 磁性件之间、与钢件之间吸附 → 振动盘内易互吸成串、卡料. 优先料管叠放 + 底部错位推料, 或料盘隔离; 分料推力按实测分离力 × 2 以上设计.
- 铁屑 / 铁粉: 会吸附在产品上影响测量和外观. 设备内不做产生铁屑的加工, 加吹气/粘尘清洁工位.
- 表磁测量误差来源 (按影响从大到小排查): 探头与产品间隙 → 产品回转跳动 (同心度) → 探头位置/角度 → 温度 → 采样密度与角度同步 → 外部磁场与电磁干扰.
  - 间隙: 探头用硬限位定距或接触定距, 不靠气缸行程末端浮动位置.
  - 跳动: 以内孔芯轴定位回转, 控制芯轴跳动.
  - 温度: 钕铁硼剩磁温度系数约 -0.10~-0.12 %/°C, 铁氧体约 -0.18~-0.20 %/°C; 温差大时做温度补偿或控制测量环境.
  - 采样: 角度编码器触发采样, 每极采样点足够分辨峰值 (例如 24 极每极 ≥ 20 点).
  - 干扰: 霍尔信号线屏蔽, 远离伺服动力线和电磁阀线圈.
- 相关性: 自制设备与基准设备 (高斯计/客户设备) 用同一批样件做相关性, 求补偿系数; 相关性设置完成前禁止进入生产全检界面.
- 磁阻尼滚轮模组: 手感测试用伺服带动滚轮 + 扭矩传感器 + 编码器记录扭矩-角度曲线, 统计峰值、谷值、峰谷差和段落数; 噪音测试放隔音罩并与其他工位冲击动作错开.
